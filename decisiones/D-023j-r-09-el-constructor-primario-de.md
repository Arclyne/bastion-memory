# D-023j · R-09 · El constructor primario de un record posicional cuenta para el límite de 3…
- sobre: 2.2.2 (L-02)
- Jose decidió: El constructor primario de un record posicional **cuenta** para el límite de 3 parámetros. Un record con más campos se agrupa en otro record o pasa a propiedades `init` con inicializador de objeto.
