# D-021j · R-07 · Las clases Rules del dominio pasan a singular con el sufijo Policy, como…
- sobre: 2.4.1
- Jose decidió: Las clases `*Rules` del dominio pasan a singular con el sufijo `Policy`, como `LockoutPolicy`: `AccountPolicy`, `ChatPolicy`, `FriendCodePolicy`, `FriendshipPolicy`, `MatchmakingPolicy`, `RoomPolicy`. Cada una se renombra al revisar su archivo.
