# D-049j · R-35 · El sufijo Store es solo para los datos locales del cliente…
- sobre: 2.14.2
- Jose decidió: El sufijo `Store` es solo para los datos locales del cliente (`LanguagePreferenceStore`). Lo que guarda en la base desde el servidor se llama `Repository`, también si abre su propio contexto por operación (`MatchRepository`, `RoomRepository`).
