# D-013j · journal D-06 · La prioridad es la facilidad de lectura
- Jose decidió: **La prioridad es la facilidad de lectura.** Un `return` se lee de un vistazo: si la expresión hace más de un paso (restar, convertir, redondear), cada paso va en una variable con nombre antes del `return`. Se evita repetir código, pero sin repartir lo que describe una misma cosa en varios lugares (por ejemplo, los valores iniciales de una clase no se dividen entre declaraciones y constructores). Toda propuesta se juzga primero por cómo se lee.
