# Q-07a · Chat de lobby y chat privado sin caso de uso

El código tiene además chat de lobby (`IChatService.SendChatMessage`, `OpenLobbyChat`) y conversaciones privadas entre amigos (`IConversationService`). Ningún caso de uso del alcance los menciona. ¿Se agregan a los requisitos o son un agregado del equipo?
Solo se leyeron las precondiciones y el flujo normal de CU-20.
